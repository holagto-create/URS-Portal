📖
What this guide covers: Complete step-by-step instructions to build the ISRM Digital Operations System from scratch using free Google Workspace tools — Google Sheets (dashboard), Apps Script (automation), Google Forms (digital FM-RIS-002 and FM-RIS-003), Google Docs (FM-RIS-059 and FM-RIS-060 templates), and Google Sites (ISRM Web Portal). Estimated setup time: 3–4 hours for full deployment.
⚠️
Form Code Update: These instructions use the official Revision 01 form codes effective 30 September 2025: FM-RIS-002, FM-RIS-003, FM-RIS-059, FM-RIS-060. The center name is Research, Innovation, and Sustainable Extension Center (RISE Center). The officer is the ISM Officer and reports to the RISE Center Director. FM-RIS-060 is addressed to the Finance Office (not Accounting Office).

Apps Script Installation
The automation engine — install inside the Google Sheets dashboard
1

Open the Apps Script Editor

a
In your Google Sheets dashboard, click the menu: Extensions → Apps Script
b
A new browser tab opens — the Apps Script editor. Rename the project from "Untitled project" to: ISRM Operations Suite v2.0
c
You will see one file in the left panel: Code.gs. Click on it — it will show some default code.
2

Paste the Script Code

a
Select all existing code in Code.gs (Ctrl+A / Cmd+A) and delete it.
b
Open the file isrm_apps_script_v3.js in any text editor. Select all (Ctrl+A), copy (Ctrl+C).
c
Back in the Apps Script editor, paste (Ctrl+V) the entire script into Code.gs.
d
Click Save (Ctrl+S or the floppy disk icon). The editor should show no syntax errors (no red underlines).
3

Update the CONFIG Object

At the top of Code.gs, find the CONFIG object. Update these values:

CONFIG KeyWhat to EnterWhere to Get It
FM_RIS_059_TEMPLATE_ID Google Doc ID of your FM-RIS-059 template Phase 5, Step 1
FM_RIS_060_TEMPLATE_ID Google Doc ID of your FM-RIS-060 template Phase 5, Step 2
OUTPUT_FOLDER_ID Folder ID of "ISRM Generated Reports" Phase 1, Step 2
ISM_OFFICER_EMAIL Your SLU email address (e.g., [email protected]) Your own email
RISE_CENTER_DIRECTOR_EMAIL RISE Center Director's email RISE Center office
⚠️
Do Phases 4 and 5 first to get the Google Form URL, Doc template IDs, and Folder ID before you can complete the CONFIG. You can come back to this step.
4

Run setupDashboard() — Build the Sheet Structure

a
In the Apps Script editor, click the function dropdown (top toolbar, shows "Select function") and choose setupDashboard.
b
Click the ▶ Run button.
c
First-time authorization: Google will ask for permissions. Click Review permissions → Choose your SLU account → Advanced → Go to ISRM Operations Suite (unsafe) → Allow.
This is safe — it's your own script on your own account.
d
Switch back to the Google Sheets tab. You will see three sheets created at the bottom: Clients, URS_Registry, Financial_Summary — all with navy-blue headers and data validation.
e
An alert dialog will confirm: "✅ ISRM Dashboard Initialized Successfully!" Click OK.
5

Add the Custom Menu to Google Sheets

a
Back in the Apps Script editor, run the function onOpen (select from dropdown → Run).
b
Switch to the Sheets tab and reload the page (F5 or Ctrl+R). After reloading, you will see a new menu item "🎯 ISRM Operations" in the Google Sheets menu bar.
c

Add Form Fields — EXACT LABELS REQUIRED

The Apps Script's onFormSubmit() uses e.namedValues["Label"] to pull responses. The field labels in your Google Form must exactly match the labels in the table below.

🔄
v3 Change — aligned with the original FM-RIS-002 paper form:
✅ Item 1 "Date" ADDED — present at the top-right of the original FM-RIS-002 paper form. The Apps Script captures get('Date') and stores it as the official request date (falls back to submission timestamp if blank).
❌ Old Item 10 "Affiliation" REMOVED — not present in the original FM-RIS-002. Affiliation (SLU / Non-SLU) is determined by the ISM Officer after reviewing the client's School field, then manually entered in the Affiliation column (Col K) of the Google Sheets dashboard. If Non-SLU, the ISM Officer also adjusts Total Fee (Col N) — the 60/40 split auto-recalculates via the onEdit() trigger.

Common Issues and Fixes

IssueCauseFix
Form submit doesn't fire onFormSubmit Trigger not set Re-run setupFormTrigger() from the ISRM Operations menu
PDF shows "PASTE_YOUR_..._HERE" in title Template Doc ID not updated in CONFIG Update CONFIG, save script, re-run generation
Email not received Wrong email in CONFIG, or Gmail quota hit Check CONFIG email fields; test with your own email first
"No table found in template Doc" error Template Doc has no table, or table is the second table Ensure FM-RIS-059/060 template Doc has a table as the very first object after the letterhead; remove any above-table elements that might be tables
60/40 doesn't auto-calculate onEdit is a simple trigger — only fires on direct edits, not programmatic Works correctly for manual edits. For script-appended rows, values are pre-computed in onFormSubmit()
Authorization error Script needs new permissions after code update In Apps Script: Run any function → re-authorize when prompted

Semester Maintenance & Operations
Recurring tasks at start and end of each semester
▶

Start of Semester Tasks

  • Update URS Registry — Add/remove URS; update AY Appointed for newly appointed statisticians
  • Archive last semester's data — Export Clients sheet as CSV/XLSX to Client Records Archive folder
  • Clear the Clients sheet — Delete all data rows (NOT the header row) for the new semester
  • Update fees if changed — Edit the FEES object in the Apps Script CONFIG if the fee schedule changes
◼

End of Semester Tasks

  • Generate FM-RIS-059 — 🎯 ISRM Operations → Generate Reports → FM-RIS-059
  • Generate FM-RIS-060 — 🎯 ISRM Operations → Generate Reports → FM-RIS-060 (after all OR numbers are entered)
  • Print and get signatures — Print PDFs → ISM Officer signs → RISE Center Director "Noted by" → submit FM-RIS-060 to Finance Office
  • File PDFs in Drive — Signed scans go into Client Records Archive folder for the semester
📞
Questions during setup? Most issues involve incorrect field label spelling in the Google Form (must exactly match e.namedValues keys in the script) or missing {{PLACEHOLDER}} tags in the Google Doc templates. Check the isrm_form_templates_v2.html reference file for the exact tag positions. The Apps Script execution log (Apps Script editor → Executions on left sidebar) shows detailed error messages for any failed runs.
